This page is the file `content/index.md`. Edit it and reload the page to see the change.

While the CMS is on and this file exists, it's the home page. Delete or rename
the file to get the site's own home page back (`client/src/views/HomeView.vue`).

- [About](/about) is `content/about.md`. It's in the menu because of `menu: true` at the top of the file.
- [Blog](/blog) is the `content/blog/` folder: a list of the pages inside it.
- The guide for all of this is in [the CMS docs](/docs/CMS).
